Forge is a minimal iOS app for tracking weight lifting workouts. Workflow is simple: 

- Start at History screen (shows past completed workouts) → tap Start Workout to navigate to the Plan Selector
- List of workout plans visible plus a New button and a re-order button. New button allows user to create new workout plans. Workout plans have exercises with a number of sets. Each set has reps (repetitions to complete for each exercise) or an option to do that specific set until failure
- User taps the start button on a workout plan to start it. A 3 second timer appears (that can be skipped if tapped). 
- When the user finishes a set for an exercise, they tap the checkmark next to that set in that exercise. A hard-coded 30-second timer appears that can be skipped, overlayed on top of the UI, preventing the user from interacting with the app.
- Adjustments can be made to each exercise's number of sets, weights and reps (i.e. logging a change) - these changes can be applied to all of the sets of an exercise, for convenience or specific sets.
- New exercises can be added during a workout. Order can be re-arranged via the edit button. When the user is done the workout, they tap Done and are brought back to the history view screen, where their newly completed workout will be visible.
